# `host_coordinator` Domain

Coordinates the Windows desktop Tauri v2 companion host (`use_desktop_host_controller.ts`), bridging native Rust telemetry with `@exile-hud/core` and the Cloudflare edge relay:
- **Tauri IPC Bridge (`tauri_ipc_adapter.ts`):** Wraps native Rust commands for `Client.txt` byte-offset detection/tailing, `PathOfExile.exe` process heartbeat, Windows Credential Manager `POESESSID` storage + GGG `character-window` polling, Windows clipboard regex writing, foreground passive-tree hotkey (`P`) toggling, tray status icons, and AppData JSON disk stores (`saved_pob_profile.json`, `saved_campaign_progress.json`).
- **Telemetry Reduction (`desktop_telemetry_bridge.ts`, `ggg_character_sync_reducer.ts`):** Applies PoB compilation, selective set inspection, log lines, GGG character snapshots, viewer commands (`toggle_checkpoint`, `toggle_gem`, `viewer:reset_progress`, `viewer:request_sync`), and foreground hotkey transitions.
- **Focused Persistence & Relay Helpers:** Split cleanly under the `< 300`-line rule across `campaign_progress_persistence_client.ts`, `pob_profile_persistence_client.ts`, `client_log_sync_helper.ts`, `passive_tree_hotkey_sync_helper.ts`, `desktop_host_settings_storage.ts`, and `relay_host_connection.ts`.
