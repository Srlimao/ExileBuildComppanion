# Checkpoint Graph Domain

Owns zone disambiguation, campaign DAG construction, and state reduction (`packages/core/src/features/checkpoint_graph/`):
- `area_dominator_resolver.ts`: Computes and `WeakMap`-caches strict BFS dominators (excluding `isIgnoredGraphEdge` portals such as `2_10_town->2_10_6` and `1_4_town->1_4_6_3`) and exports `getPriorActImpliedAreaIds` so only strictly prior Acts (`priorAct < targetAct`) auto-reconcile on mid-campaign Act entry; unvisited maps in the current Act never auto-complete by dominance.
- `checkpoint_directed_graph_builder.ts` & `campaign_quest_group_assigner.ts`: Classifies route steps (`stepKind`, offer-scoped `isSkillBookQuestOffer`, Labyrinth `*_Labyrinth_boss_3` ascend steps), annotates contiguous Visit Blocks with `expectedExitAreaId`, `prerequisiteAreaIds`, and `isOptionalDetour`, and tags sequential 10-Act story-gate `questGroupId` / `isMandatoryGate` metadata from `poe1_campaign_quest_groups.ts`.
- `campaign_quest_group_evaluator.ts`: Evaluates sequential Mandatory Quest Groups per Act so `ActiveChecklistWidget` stays pinned on the earliest group with unvisited/incomplete mandatory maps (while keeping optional side detours, Skill Books, and Lab Trials non-blocking and allowing manual checkbox override).
- `checkpoint_progression_evaluator.ts` & `checkpoint_progression_reducer.ts`: Tracks `visitedAreaIds` and `clearedAreaIds`, requires explicit visit/exit (or manual check-off) within the current Act, gates completion on Visit-Block exits and prerequisite clearance, guards against `player_slain` town/hideout respawns, and prioritizes prerequisite-cleared `SKILL_BOOK` checkpoints on `skill_points_received`.
- `lab_and_passives_reconciler.ts`: Auto-completes unlocked tier Labyrinth trials (and prior Lab tiers) upon entering interior Labyrinth rooms (`1_Labyrinth_*`–`EndGame_Labyrinth_*`) or via allocated Ascendancy nodes / `/passives` Ascendancy summary lines, and reconciles `/passives` quest summary headers and parenthesized `(N from <Quest>)` lines against campaign `SKILL_BOOK` checkpoints.
- `zone_context_disambiguator.ts`: Parses PoE `Client.txt` lines (including `/passives` Ascendancy, level, quest-summary header, and parenthesized quest lines) and disambiguates duplicate zone names across Acts 1–5 / 6–10.
- `campaign_progress_persistence.ts`: Extracts and restores completed/soft-completed checkpoints, `visitedAreaIds`/`clearedAreaIds`, and gem states with category-agnostic semantic key migration and explicit reset preservation.
- `initial_session_snapshot_factory.ts`: Builds the initial PoB-backed HUD snapshot before live telemetry begins.
